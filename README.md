# ML_Project

### Tema

**Predicción probabilística de resultados de partidos de fútbol mediante Machine Learning**, utilizando únicamente información disponible antes del partido.

### Qué se abordará

- **Target:** probabilidad de `Victoria Local`, `Empate` o `Victoria Visitante`.
- **Variables:** rendimiento de los últimos 5 partidos, goles, tiros, tiros a puerta, corners y otras estadísticas históricas; además de características agregadas de los jugadores.
- **Modelos:** un baseline sencillo y modelos como **Logistic Regression, Random Forest y XGBoost**.
- **Evaluación:** Accuracy, F1, **Log Loss/Brier Score** y calibración de probabilidades.
- **Apuestas:** comparar las probabilidades del modelo con las **cuotas de las casas de apuestas** y realizar un **backtest** para evaluar si podrían identificar apuestas con valor.
